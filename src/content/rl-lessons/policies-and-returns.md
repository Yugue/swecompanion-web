# 1.5 Policies, returns, discounting, and episode boundaries

## 1. A policy specifies behavior

A **stochastic policy** π(a given s) assigns action probabilities. A **deterministic policy** μ(s) selects one action. Either may be a table or learned function.

Policy specifies behavior; reward specifies feedback. Training changes behavior without necessarily changing the reward.

## 2. Return combines future rewards

A **return** combines future rewards:

\[
G_t=\sum_{k=0}^{T-t-1}\gamma^k R_{t+k+1}
\]

Gₜ is return at time t; T is episode end; R is reward; k counts future steps; γ∈[0,1] is the **discount factor**. Continuing discounted tasks commonly use γ<1 and bounded rewards.

Rewards [2,0,10] at γ=0.9 give 2+0+0.81×10=10.1. The first reward is undiscounted.

## 3. Discounting changes what is preferred

γ=0 values only the next reward; larger γ weights distant rewards more. A constant stream r has value r/(1−γ), so value scales grow too.

The **effective horizon** 1/(1−γ) is about 10 steps at 0.9 and 100 at 0.99. It is a weighting scale, not a cutoff.

Discounting changes the preferred behavior, not just numerical stability.

## 4. State the objective explicitly

The policy objective averages return:

\[
J(\pi)=\mathbb E_{S_0\sim\rho_0,\,\tau\sim\pi}[G_0]
\]

J is expected performance; ρ₀ is the initial-state distribution; τ is a trajectory generated by policy π and the environment. Improve J rather than each immediate reward.

Finite episodes may use γ=1. A continuing **average-reward objective** measures long-run reward per step; it need not rank policies like discounted return.

## 5. Termination is not external truncation

| Boundary | Meaning | Continuation value |
|---|---|---|
| Genuine terminal state | The modeled task has ended | Zero |
| External collection time limit | Interaction stopped while the task continues | Usually bootstrap |
| Genuine finite task deadline | Time is part of the task | Zero at that deadline |

**Bootstrapping** fills in an unobserved future with an estimated continuation value. Whether that future exists depends on the boundary.

For truncation, bootstrap from the final observation before reset. Stop recursive calculations at the boundary before they reach a new episode.

## 6. A numerical boundary check

With reward 1, γ=0.9, and successor value 5: continuing target=5.5; genuinely terminal target=1. Confusing the boundaries adds an error of 4.5.

```python
continuation = 0.0 if terminated else next_value
target = reward + gamma * continuation
```

Use the actual successor’s next_value, not an automatically reset observation.

## 7. Compute a return backward

Compute Gₜ=Rₜ₊₁+γGₜ₊₁ backward, starting with zero after genuine termination:

```python
ret = 0.0
for reward in reversed(rewards):
    ret = reward + gamma * ret
```

Positive reward scaling preserves unregularized policy rankings, but changes target magnitudes and may require optimizer or regularization adjustments.

```text
time →        0       1       2
reward:       1       2       3
discount:     1      0.5     0.25
contribution: 1       1      0.75
```

At γ=0.5 the displayed return is 2.75. The rewards stay fixed; their weights in the objective change.
